# Stage A 30 轮结果分析（2026-09-20）

## 结论

FBD 已学到提示相关的功能区分，值得继续做受控实验。但它在当前 holdout 上稳定落后 LAS，并有大量对象功能区分幅度不足。下一步优先控制分割损失差异、验证 union 项影响；不建议直接扩大 K、长时间续训或立即引入 Stage B。

本次实际运行了两个最佳 checkpoint 的完整验证分析，没有更新权重、启动训练或读取正式测试数据。分析入口为 `tools/analyze_stage_a_holdout.py`。服务器产物为 `/home/junbo/wyn/codes/CMAT_my/work/stage_a/controlled/analysis30_20260920/`，含各模型 JSON、逐提示预测 NPZ 和日志。本地同名 work 目录保存 JSON 与训练状态。

源码核对发现本地与服务器尚未完全同步：服务器 LAS 包含完整 encoder wrapper 冻结及 train/eval 覆盖，indexed dataset 包含共享图像池解析和最少功能数过滤。本次分析在服务器实际代码上运行；损失工厂、FBD 损失和指标源码在换行归一化后与本地一致，LAS 损失实现也一致。未覆盖本地已有源码改动，复现应使用服务器当前代码。本地 work 分析目录另保存这两个有差异文件的服务器副本。

## 评估范围与方法

- 原训练作业 `continue30_20260920_114200` 中两组状态均为 completed，30 轮历史完整。
- 按验证 aIoU 选定 FBD 第 29 轮、LAS 第 24 轮的 `checkpoint_best.pth`，严格加载权重。
- 相同 512 个验证对象、1157 个有效提示、2048 点；模型 eval、无增强；未使用测试集。
- 原提示、对象内循环交换提示（GT 保持原位）和另一组前向随机种子各完整评估一次。原提示和交换提示在每个 batch 前重置相同 Python、NumPy、PyTorch 随机种子。
- 数据集点采样和图像选择固定，但模型内部 FPS 有随机初始点。替代随机种子评估用于估计一次前向随机性影响，不构成训练多 seed 或统计置信区间。
- FBD 与 LAS 的点云编码 batch 形状不同，因此相同种子不保证两模型内部 FPS 点完全一致。对象内功能预测差异对 LAS 也可能包含内部采样差异。
- 指标沿用仓库实现：全部有效提示的点展平计算；AUC/aIoU 的 GT 以 >0.5 二值化，aIoU 使用 0 到 1 的 20 个阈值，SIM 是余弦相似度。这里不是逐对象指标均值，也不直接等同于外部论文指标。

| LAS 原提示 | 0.16528 | 0.80764 | 0.66967 | 0.12541 |
| FBD 交换提示 | 0.04329 | 0.47708 | 0.37717 | 0.20753 |
| LAS 交换提示 | 0.03336 | 0.45979 | 0.29956 | 0.19759 |

FBD 与 LAS 的 aIoU 差距为 2.693 个百分点；两次固定模型的前向随机种子差异分别约 0.047 和 0.033 个百分点。本次观察到的随机波动远小于模型间差距，但不能据两次前向推断训练随机性。

按功能等权平均各功能的 pooled aIoU，FBD/LAS 为 0.15001/0.16884；按类别等权平均为 0.09873/0.12565。重新加权后差距仍存在，不能仅归因于高频类别权重。

## 功能区分：已有效，但存在局部不足

FBD 交换提示后 aIoU 下降约 68.7%，LAS 下降约 79.8%；二者都明显利用了提示，不能把 FBD 判断为忽略提示或整个选择器完全塌缩。

| 诊断量 | FBD | LAS |
|---|---:|---:|
| 对象内功能预测两两 MAE，按 pair 平均 | 0.13670 | 0.18430 |
| 相同 pair 的 GT MAE | 0.17534 | 0.17534 |
| 对象平均功能预测差异 < 1e-6 | 0/512 | 0/512 |
| 功能区分幅度不足的对象（下述经验定义） | 226/508 | 44/508 |
| 交换提示引起的预测 MAE | 0.14536 | 0.19119 |
| 替代前向种子引起的预测 MAE | 0.02869 | 0.02336 |

经验定义：先选对象内 GT 两两平均 MAE >0.02 的 508 个对象，再统计预测两两平均 MAE 小于该对象 GT 差异 25% 的对象。这是诊断阈值，不是准确率或理论验收门槛。FBD 约 44.5% 的这些对象区分幅度不足，LAS 约 8.7%。总体 pair 均值会掩盖这类对象；“没有完全相同预测”也不等于区分充分。

FBD 的 argmax 计数为 `[0,732,0,7,0,56,362,0]`，两个主要基底占 94.6%。平均 softmax 权重为 `[0.00363,0.62321,0.00356,0.01661,0.00360,0.04637,0.29956,0.00345]`，归一化熵为 0.10453。集中不仅出现在 argmax，也出现在平均权重；但基底利用不均衡的原因仍可能包括数据分布、基底冗余或监督目标，不能仅凭该现象认定因果。

## 必须控制的实验混杂

1. **分割损失不同。** FBD 的 focal 对软标签使用插值的 p_t 和 alpha；LAS 将正负项分开加权。FBD Dice 是逐有效提示的前景 Dice 均值；LAS 是整批展平的前景和背景双向 Dice。FBD 另有 0.2×union。配置里 FBD 的 `focal_weight: 0.5` 未被 FunctionalBasisLoss 工厂使用，实际分割项是 focal+dice；分析时不能按 YAML 字面误读为 0.5×focal。
2. **可训练参数不同。** FBD 为 1,514,760，LAS 为 3,354,625；FBD 约为 LAS 的 45.2%。这是现有方法比较，不是参数量匹配的结构消融。不能据此说 FBD 一定更快，当前没有做推理耗时基准。
3. **验证范围有限。** 此 holdout 是 Unseen_obj setting 的训练对象内部划分，且来自多标注对象。它不直接测量正式未见类别泛化；每个对象功能仅使用固定的一张验证提示图像。
4. **union 与重构可能存在目标张力。** union 用所有 sigmoid 基底的 noisy-OR，最终预测则是基底 logits 的凸组合。这两个运算不同，可能影响校准和基底利用。当前只是代码支持的机制假设，必须用关闭 union 的消融验证。

## 下一轮推荐顺序

1. 将当前两组结果作为基线保留。固定划分、验证输入和前向种子。
2. 新增 FBD 使用 LAS 同款分割损失且保留 union=0.2 的分支，与现有 FBD 比较，单独检验分割目标影响。
3. 在该分支基础上关闭 union，与上一步比较。这样可以区分分割损失与 union 的作用；不要同时改损失、K、温度和学习率。
4. 先沿用 K=8、温度 0.2、冻结骨干与相同训练调度。主要看验证 aIoU、open/support/pour、逐对象区分幅度及选择权重分布。
5. 有方向性结果后补两个训练 seed；固定数据划分、统一评估 seed，使训练随机性和验证采样随机性分开。之后再考虑 K=4 或 Stage B 关系监督。

Stage B 关系损失在当前模型工厂中仍被明确拒绝，不能只将配置权重改为非零就启动。现阶段建议继续 Stage A 受控实验，暂不投入 100 轮长训或扩大基底数量。
